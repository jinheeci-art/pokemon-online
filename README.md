# 🌊 포켓몬 쓰나미 구조대 (온라인 게임)

## 게임 방법
- **로그인/회원가입** 후 입장
- **이동**: 방향키 또는 WASD (휴대폰은 화면 버튼)
- 위험 구역(오른쪽)에 있는 포켓몬 옆에서 **E 키** → 포켓몬을 데려가요
- 왼쪽 **🏠 안전구역**으로 돌아오면 → **📦 내 창고**에 자동 보관
- 🌊 **쓰나미**가 주기적으로 오른쪽에서 몰려와요. 휩쓸리면 들고 있던 포켓몬을 잃어요!
  → 안전구역이나 **⛰️ 언덕** 위로 피하세요
- 오른쪽 구역일수록(★ 많을수록) 강한(CP 높은) 포켓몬이 있지만 더 위험해요. 뮤는 아주 희귀!
- **👥 트레이너** 버튼 → 다른 사람에게 **⚔️ 배틀** 신청 (둘 다 안전구역에 있어야 해요)
- 배틀에서 이기면 **진 사람이 내보낸 포켓몬을 가져와요!**

## 파일 설명
| 파일 | 하는 일 |
|---|---|
| `server.js` | 게임 서버 (로그인, 쓰나미, 창고, 배틀) |
| `public/index.html` | 게임 화면 (브라우저에서 보이는 부분) |
| `package.json` | 필요한 프로그램 목록 |
| `data/db.json` | 계정과 창고가 저장되는 곳 (자동으로 만들어져요) |

## 내 컴퓨터에서 실행하기
1. https://nodejs.org 에서 **Node.js (LTS)** 설치
2. 이 폴더에서 터미널(명령 프롬프트)을 열고:
   ```
   npm install
   npm start
   ```
3. 브라우저에서 http://localhost:3000 접속

## 난이도 바꾸기
`server.js` 맨 위의 숫자를 바꾸면 돼요.
- `CALM_TIME` 쓰나미 사이 쉬는 시간 / `WAVE_SPEED` 쓰나미 속도
- `WILD_COUNT` 야생 포켓몬 수 / `PLAYER_SPEED` 내 속도
